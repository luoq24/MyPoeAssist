# app_store_manager 摆摊辅助 — 开发进度与规划

> 更新日期：2026-08-06

## 一、项目概述

基于 PyQt6 的 POE2 国服摆摊辅助工具。核心目标：**自动调整摊位中道具的价格**，并规划后续**自动上架**。

当前已实现「单个改价」的完整自动化主流程（F4 触发），并支持通货降级、币种切换、多高度档适配。

---

## 二、已完成功能

### 1. 单个改价自动化（F4 触发）
完整流程：
1. 当前鼠标位置**右键** → 弹出价格调整界面
2. **Ctrl+C** 复制当前价格数字 → 读剪贴板解析
3. **图像识别**币种图标（多高度档遍历，取最高匹配）
4. **计算新价**（含通货降级优化）
5. **Ctrl+A 全选 + 键入**新价格
6. **币种切换**（若降级到更便宜币种，2 次单击切换下拉框）
7. **上架货物**：点击「上架货物」按钮（F3 坐标模式采集，复用 delta_y 方案）

### 2. 通货降级优化（decide_price）
- 目标混沌等价 = 当前价 × 当前币种单价 × (1 − 降幅%)
- 从当前币种向更便宜通货依次尝试，取第一个**精度损失 ≤ 10%** 的方案
- 无满足项时取损失最小的方案
- 单币种价格上限 **999**
- 示例：`2 神圣石 @20% → 8 混沌石`（不再粗暴变 1 神圣石）

### 3. 通货模板采集（F3 触发）
- **采集通货模板**：截图当前通货图标区域 → 存为选中通货的模板
- **采集切换坐标**：采集当前鼠标位置作为切换币种坐标（归一化到第 1 档）

### 4. 多高度档适配（delta_y）
- 不同道具图标高度不同 → 价格界面整体上下移动（共 4 档）
- 配置 `delta_ys`（3 个 Y 偏移），识别时遍历 4 档取最高匹配，切换到当前档 `delta_y`
- 切换坐标存第 1 档，运行时按 `delta_y` 整体偏移

### 5. 全局热键
- **F2**：批量改价（从鼠标所在格向后遍历摊位网格逐个改价，支持多格道具跳过，再次按 F2 中断）
- **F3**：采集（按 GUI 当前模式：通货模板 / 切换坐标 / 上架货物坐标）
- **F4**：修改鼠标指向的道具

## 三、文件结构

```
source/
├─ app_store_manager.py            # 应用入口（QMainWindow，热键注册）
├─ models/
│  ├─ currency_pricer.py           # 加载价格表，提供 5 种通货价格查询
│  ├─ store_automation.py          # 核心改价自动化 + 降级决策 + 币种切换 + 批量改价
│  ├─ store_manager.py             # 模型层（QObject），线程调度、模板/坐标采集入口
│  └─ bag.py                       # 网格基础(BagBase) + 摊位网格(StallPoe2，坐标待实测微调)
├─ tools/
│  ├─ hotkey.py                    # 全局热键（RegisterHotKey + Qt 原生事件过滤）
│  ├─ input_helper.py              # 鼠标/键盘辅助（右键、点击、键入、ctrl+C/A）
│  └─ screen.py                    # 固定区域截图 + 通货图标模板匹配（CurrencyMatcher）
├─ views/
│  └─ windows/
│     └─ store_manager.py          # GUI 视图（降幅、采集模式/坐标槽位、价格参考、日志）
└─ data/
   ├─ store/
   │  └─ config.json               # 坐标、delta_y、延迟等配置
   └─ store_currency/<key>/        # 通货模板图片（自动持久化）
```

## 四、关键配置（data/store/config.json）

| 配置项 | 说明 |
|--------|------|
| `price_ui.currency_region` | 通货图标区域，`y` 为第 1 档（最小高度档） |
| `price_ui.delta_ys` | 第 2/3/4 档相对第 1 档的 Y 偏移（3 个值） |
| `price_ui.currency_switch.expand` | 第一次单击展开下拉框的位置（第 1 档坐标） |
| `price_ui.currency_switch.select.<通货>` | 第二次单击选中对应通货的位置（第 1 档坐标） |
| `price_ui.put_on_shelf` | 「上架货物」按钮位置（第 1 档坐标，复用 delta_y 偏移） |
| `price_ui.match_threshold` | 模板匹配最低置信度（0.8） |
| `delays.after_move` | 鼠标移动到位后、点击前的等待 |
| `delays.after_switch_expand` | 展开下拉后等待列表弹出的等待 |
| `delays.after_switch` | 选中通货后、继续下一步的等待 |
| `delays.after_put_on_shelf` | 点击「上架货物」后的等待 |

## 八、已知注意点

- 坐标是**绝对屏幕坐标**：游戏窗口移动/分辨率变化需重新采集
- 后台线程访问剪贴板需初始化 COM（已在 `reduce_price_of_hovered_item` 处理）
- 建议直接命令行运行，脱离调试器可避免 OLE 剪贴板报错（不影响功能）
