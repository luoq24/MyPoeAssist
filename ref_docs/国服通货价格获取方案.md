# 国服 POE2 通货价格获取与过滤器生成方案

## 一、背景

通过对易刷 E-farm (exilence-next-tx-app) 的逆向分析，已定位到国服 POE2 通货价格数据的完整获取链路。本方案基于该分析结果，设计一套安全、低负载的价格获取与 PoE2 `.filter` 过滤器自动生成流程。

### 关键发现

| 项目 | 说明 |
|------|------|
| 数据源 | 自建 CDN (`cf.981001.xyz`) 上的 `fkhprice_tx2_*.txt` 文件 |
| 文件格式 | base64 编码 → gzip 压缩 → JSON 数组 |
| 更新频率 | 作者维护，分钟级时间戳缓存（约 1 小时更新一次） |
| 鉴权要求 | **无需鉴权**，CDN 公开可访问 |
| 数据覆盖 | 国服 POE2 全物品价格，通货条目 508 条 |
| 价格来源 | 标注为 `poecurrency.top`（国服 POE2 物价站） |

---

## 二、数据源选择

### 选定方案：CDN 价格文件（`fkhprice_tx2_*.txt`）

**选择理由：**

1. **安全性高**：CDN 由 Cloudflare 缓存，单次 GET 请求直接命中边缘节点，不触及源服务器
2. **压力极低**：文件按分钟级缓存，相同时间窗口内多次请求也只回源一次；每日拉取 1 次几乎零负载
3. **数据完整**：一个文件包含当前联赛全部物品价格，通货条目 (`frameType=5`) 有 508 条
4. **无需鉴权**：不涉及任何 token / 卡密 / cookie，不触碰敏感接口
5. **已验证可用**：实测拉取成功，数据结构清晰（见第七节）

**未选用的数据源及原因：**

| 数据源 | 不选用原因 |
|--------|-----------|
| 云估价 API (`/3006/culPrice1`) | 需 POST 物品数据，涉及估价逻辑，且可能需要鉴权 |
| 神圣石汇率 API (`/api/price/GetDivChaos`) | 只返回单一汇率，不含通货表 |
| poe.ninja 原始 API | 国际服数据，国服 POE2 物价不同 |
| `ninja.710421059.xyz` 镜像 | 国际服数据镜像，且增加自建服务器负载 |
| poecurrency.top 直接爬取 | 增加第三方站点压力，且 CDN 文件已整合其数据 |

## 三、价格文件详情

### 3.1 URL 构造

```
主 URL:    https://cf.981001.xyz/{1-9随机}/fkhprice_tx2_{leagueType}.txt?t={分钟级时间戳}
备用 URL:  https://www.710421059.xyz/file/fkhprice_tx2_{leagueType}.txt?t={分钟级时间戳}
```

- `{1-9}`：CDN 节点编号，随机选一个即可（实测 302 重定向会归一化，去掉节点号）
- `{leagueType}`：联赛类型数字，见下表
- `?t=`：分钟级时间戳 `Math.floor(Date.now()/60000)*60000`，用于命中 CDN 缓存

### 3.2 联赛类型 (leagueType)

从 `league.json`（同为 CDN 上的纯 JSON 文件）获取，按 `plat === "tx2"` 过滤：

| leagueType | 含义 | 文件名 |
|:---:|------|------|
| 1 | 永久 / 标准模式 | `fkhprice_tx2_1.txt` |
| 2 | 当前赛季（奥杜尔秘符） | `fkhprice_tx2_2.txt` |
| 22 | 赛季专家（奥杜尔秘符·专家） | `fkhprice_tx2_22.txt` |

**联赛列表 URL：**
```
https://cf.981001.xyz/{1-9}/remoteCode/league.json?t={时间戳}
```
注意：`league.json` 是纯 JSON（非 base64+gzip），直接 `JSON.parse` 即可。

### 3.3 解码流程

```
HTTP GET 响应体 (文本)
    ↓
trim() 去除空白
    ↓
Buffer.from(text, "base64")    // base64 解码
    ↓
zlib.gunzipSync(buffer)        // gzip 解压
    ↓
TextDecoder("utf-8").decode()  // 转字符串
    ↓
JSON.parse()                   // 得到数组
```

### 3.5 frameType 分布（实测国服 POE2 奥杜尔秘符赛季）

| frameType | 含义 | 数量 |
|:---------:|------|-----:|
| 0 | 普通（白） | 17 |
| 4 | 技能宝石（绿） | 117 |
| **5** | **通货（金）** | **508** |

**POE2 无命运卡 (frameType=6)**，过滤器仅需关注 `frameType=5`。

### 3.6 价格归一化

CDN 文件中 `calculated` 字段为**原始价格**（来自 poecurrency.top），混沌石的 `calculated` 不等于 1（实测为 82）。需做归一化处理，与易刷应用内部逻辑一致：

```javascript
// 找到混沌石的 calculated 值作为基准
const chaosItem = prices.find(p =>
  p.name === "混沌石" || p.name_en === "Chaos Orb"
);
const chaosBase = chaosItem ? chaosItem.calculated : 1;

// 归一化：所有价格除以混沌石基准值，得到混沌石等价价格
const normalized = currencies.map(c => ({
  ...c,
  chaosValue: c.calculated / chaosBase  // 混沌石等价价格
}));
```

归一化后混沌石 = 1c，便于分档比较。也可直接使用 `calculatedDiv` 字段（神圣石等价）作为替代基准。

## 四、获取方案设计

### 4.1 整体流程

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 1. 获取联赛   │────▶│ 2. 拉取价格   │────▶│ 3. 解码+过滤  │────▶│ 4. 价格归一化 │
│    列表      │     │    文件       │     │    通货条目   │     │    + 本地缓存 │
└─────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
                                                                    │
                                                                    ▼
                         ┌──────────────┐     ┌──────────────┐
                         │ 6. 输出      │◀────│ 5. 价格分档   │
                         │    .filter   │     │    分类       │
                         └──────────────┘     └──────────────┘
```

### 4.2 拉取策略（安全 & 低负载）

1. **频率**：每日拉取 1 次（满足 24 小时偏差要求）
2. **时间戳**：使用分钟级时间戳 `Math.floor(Date.now()/60000)*60000`，确保命中 CDN 缓存
3. **节点**：随机选 1-9 节点，CDN 会 302 归一化，不影响结果
4. **失败重试**：最多重试 1 次，切换到备用 URL (`710421059.xyz/file/`)
5. **本地缓存**：拉取后存为本地 JSON 文件，后续直接读本地
6. **User-Agent**：使用正常浏览器 UA，不模拟应用内请求

### 4.3 通货分档规则

归一化后按混沌石等价价格分档。以下阈值基于实测数据分布设计，可按需调整：

| 档位 | 价格范围 (混沌石等价) | 过滤器行为 | 典型物品示例 |
|------|----------------------|-----------|-------------|
| T0 - 传说 | ≥ 1000 | 高亮 + 音效 + 大字 + 小地图图标 | 卡兰德魔镜、辛格拉发辫 |
| T1 - 极高 | 100 ~ 1000 | 高亮 + 音效 + 大字 | 试炼使者圣物厅钥匙、佳华尼圣典 |
| T2 - 高价 | 10 ~ 100 | 高亮 + 音效 | 破溃宝珠、完美混沌石、雕琢威严 |
| T3 - 中价 | 1 ~ 10 | 高亮显示 | 崇高石、神圣石、完美溶剂 |
| T4 - 低价 | 0.1 ~ 1 | 普通显示 | 工匠石、点金石、催化剂 |
| T5 - 微价 | 0.01 ~ 0.1 | 暗色显示 | 低等工匠石、玻璃弹珠 |
| T6 - 忽略 | < 0.01 | 隐藏 | 远古稀释的液化愤怒等 |
| 特殊 | = 0 或无数据 | 默认显示 | 新物品/无价格物品 |

> **注意**：`calculated = 0` 的条目（无市场价格）不应隐藏，建议默认显示以免漏掉新通货。

## 五、`.filter` 过滤器生成

### 5.1 目标格式

PoE2 原生 `.filter` 文件，语法与 POE1 基本兼容。核心结构：

```
Show
    Class "Currency"
    BaseType "Divine Orb"
    SetFontSize 45
    SetTextColor 255 255 255 255
    SetBorderColor 255 0 0 255
    SetBackgroundColor 0 0 0 255
    PlayAlertSound 1 300
    MinimapIcon 0 Red Star
```

### 5.2 过滤器匹配方式

POE2 通货通过 `BaseType` 匹配，使用条目的 `name_en` 字段（英文名）。部分通货可能需要用 `baseType_en` 匹配。

```javascript
// 按档位生成过滤器块
function generateTierBlock(tier, items) {
  const lines = [];

  if (tier.display === 'hide') {
    lines.push('Hide');
  } else {
    lines.push('Show');
  }

  lines.push('    Class "Currency"');
  // 每个通货单独一条 BaseType，或合并为 OR 列表
  const baseTypes = items
    .map(i => i.name_en || i.name)
    .filter(Boolean)
    .map(n => `"${n}"`)
    .join(' ');
  lines.push(`    BaseType ${baseTypes}`);

  // 视觉设置
  if (tier.fontSize) lines.push(`    SetFontSize ${tier.fontSize}`);
  if (tier.textColor) lines.push(`    SetTextColor ${tier.textColor}`);
  if (tier.borderColor) lines.push(`    SetBorderColor ${tier.borderColor}`);
  if (tier.bgColor) lines.push(`    SetBackgroundColor ${tier.bgColor}`);
  if (tier.sound) lines.push(`    PlayAlertSound ${tier.sound}`);
  if (tier.minimapIcon) lines.push(`    MinimapIcon ${tier.minimapIcon}`);

  return lines.join('\n');
}
```

### 6.1 拉取与解码（伪代码）

```javascript
// fetch_prices.mjs
import https from 'https';
import zlib from 'zlib';
import { writeFileSync } from 'fs';

const CDN_BASE = 'https://cf.981001.xyz';
const FALLBACK_BASE = 'https://www.710421059.xyz/file';
const PLATFORM = 'tx2';
const LEAGUE_TYPE = 2;  // 当前赛季

function httpGet(url) {
  return new Promise((resolve, reject) => {
    const opts = {
      headers: { 'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)' }
    };
    function fetch(u, depth = 0) {
      https.get(u, opts, res => {
        if (res.statusCode >= 300 && res.statusCode < 400 && res.headers.location) {
          if (depth > 5) return reject(new Error('too many redirects'));
          return fetch(res.headers.location, depth + 1);
        }
        let data = '';
        res.on('data', c => data += c);
        res.on('end', () => resolve(data));
      }).on('error', reject);
    }
    fetch(url);
  });
}

function getTimestamp() {
  return Math.floor(Date.now() / 60000) * 60000;
}

// 获取联赛列表（可选，用于动态确认当前赛季 leagueType）
async function fetchLeagues() {
  const node = Math.floor(Math.random() * 9) + 1;
  const url = `${CDN_BASE}/${node}/remoteCode/league.json?t=${getTimestamp()}`;
  const text = await httpGet(url);
  return JSON.parse(text).filter(l => l.plat === 'tx2');
}

// 拉取 POE2 价格文件
async function fetchPrices(leagueType) {
  const node = Math.floor(Math.random() * 9) + 1;
  const fileName = `fkhprice_${PLATFORM}_${leagueType}.txt`;
  const ts = getTimestamp();
  const url = `${CDN_BASE}/${node}/${fileName}?t=${ts}`;

  let text;
  try {
    text = await httpGet(url);
  } catch {
    text = await httpGet(`${FALLBACK_BASE}/${fileName}?t=${ts}`);
  }

  // 解码: base64 → gunzip → JSON
  const buf = Buffer.from(text.trim(), 'base64');
  const json = zlib.gunzipSync(buf).toString('utf-8');
  return JSON.parse(json);
}

// 过滤通货 + 归一化
function processCurrencies(prices) {
  const currencies = prices.filter(item => item.frameType === 5);

  // 找混沌石基准
  const chaos = currencies.find(c =>
    c.name === '混沌石' || c.name_en === 'Chaos Orb'
  );
  const base = chaos ? chaos.calculated : 1;

  // 归一化为混沌石等价
  return currencies.map(c => ({
    name: c.name,
    name_en: c.name_en,
    baseType_en: c.baseType_en,
    chaosValue: c.calculated / base,
    rawValue: c.calculated,
    count: c.count,
    category: c.category,
  }));
}
```

### 6.2 过滤器生成（伪代码）

```javascript
// generate_filter.mjs
import { writeFileSync } from 'fs';

const TIERS = [
  { name: 'T0', min: 1000,  display: 'show',  fontSize: 45,
    textColor: '255 255 255 255', borderColor: '255 0 0 255',
    bgColor: '100 0 0 255', sound: '1 300', minimapIcon: '0 Red Star' },
  { name: 'T1', min: 100,   display: 'show',  fontSize: 42,
    textColor: '255 255 255 255', borderColor: '255 128 0 255',
    bgColor: '60 30 0 255', sound: '1 300', minimapIcon: '0 Orange Star' },
  { name: 'T2', min: 10,    display: 'show',  fontSize: 40,
    textColor: '255 255 0 255', borderColor: '200 200 0 255',
    bgColor: '50 50 0 255', sound: '1 200' },
  { name: 'T3', min: 1,     display: 'show',  fontSize: 36,
    textColor: '255 255 0 255' },
  { name: 'T4', min: 0.1,   display: 'show',  fontSize: 32,
    textColor: '200 200 200 255' },
  { name: 'T5', min: 0.01,  display: 'show',  fontSize: 28,
    textColor: '120 120 120 255' },
  { name: 'T6', min: 0,     display: 'hide' },
];

function classifyPrice(chaosValue) {
  for (const tier of TIERS) {
    if (chaosValue >= tier.min) return tier;
  }
  return TIERS[TIERS.length - 1];
}

function generateFilter(currencies, leagueName) {
  const lines = [];
  lines.push('# ============================================');
  lines.push('# 国服 POE2 通货过滤器 - 自动生成');
  lines.push(`# 联赛: ${leagueName}`);
  lines.push(`# 生成时间: ${new Date().toISOString()}`);
  lines.push(`# 通货条目: ${currencies.length}`);
  lines.push('# ============================================');
  lines.push('');

  for (const tier of TIERS) {
    const items = currencies.filter(c => classifyPrice(c.chaosValue) === tier);
    lines.push(`# === ${tier.name} (${items.length} items) ===`);

    if (tier.display === 'hide') {
      lines.push('Hide');
    } else {
      lines.push('Show');
    }
    lines.push('    Class "Currency"');

    // 用 name_en 匹配，回退到 name
    const baseTypes = items
      .map(i => i.name_en || i.name)
      .filter(Boolean)
      .map(n => `"${n}"`)
      .join(' ');
    if (baseTypes) {
      lines.push(`    BaseType ${baseTypes}`);
    }

    if (tier.fontSize) lines.push(`    SetFontSize ${tier.fontSize}`);
    if (tier.textColor) lines.push(`    SetTextColor ${tier.textColor}`);
    if (tier.borderColor) lines.push(`    SetBorderColor ${tier.borderColor}`);
    if (tier.bgColor) lines.push(`    SetBackgroundColor ${tier.bgColor}`);
    if (tier.sound) lines.push(`    PlayAlertSound ${tier.sound}`);
    if (tier.minimapIcon) lines.push(`    MinimapIcon ${tier.minimapIcon}`);

    lines.push('');
  }

  // 无价格通货默认显示
  const noPrice = currencies.filter(c => c.rawValue === 0);
  if (noPrice.length > 0) {
    lines.push('# === 无价格通货 (默认显示) ===');
    lines.push('Show');
    lines.push('    Class "Currency"');
    const baseTypes = noPrice
      .map(i => i.name_en || i.name)
      .map(n => `"${n}"`)
      .join(' ');
    lines.push(`    BaseType ${baseTypes}`);
    lines.push('    SetFontSize 36');
    lines.push('');
  }

  return lines.join('\n');
}
```

## 七、安全与合规说明
